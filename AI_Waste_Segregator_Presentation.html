Introduction

Automatic Dry & Wet Waste Segregation using Artificial Intelligence, Robotics and Smart Automation to reduce manual handling and improve recycling efficiency.

Problem Statement

Manual segregation causes health risks and low recycling efficiency. Industry requires intelligent automated waste segregation systems.

Dry Waste

Plastic, Paper, Cardboard, Metal, Glass – Recyclable materials.

Wet Waste

Food waste, Vegetable peels, Fruit waste – Biodegradable & compostable.

System Modules

  • Robotic Arm (ESP32 + Servo Motors + Bluetooth Control)
  • Smart Bin (Dual Compartments + Sensors)
  • AI Web Application (Camera + Image Classification + Arduino)

Working Flow

Capture → Classify → Controller → Motor Activation → Correct Bin

Future Scope

Multi-category segregation, Deep Learning accuracy, Cloud Monitoring, Solar Smart Bins, Municipal Integration.
